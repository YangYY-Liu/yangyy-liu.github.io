# Yang Liu's Academic Homepage

Source for [yangyy-liu.github.io](https://yangyy-liu.github.io/).

The site uses the responsive [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) Jekyll theme, based on the customized layout from [zeaver/zeaver.github.io](https://github.com/zeaver/zeaver.github.io). Site content is maintained in `_pages/`; personal metadata and social links are configured in `_config.yml`.

## Local preview

```bash
bundle install
bundle exec jekyll serve --livereload
```

Then open <http://127.0.0.1:4000>.
